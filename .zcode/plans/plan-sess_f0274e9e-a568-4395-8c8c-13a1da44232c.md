# Pomodoro TUI — Comprehensive UI/UX Improvement Plan

## Context

The app is a skeleton: only `cmd/main.go → src/views/{app,main_view}.go` is alive; the timer shows `00:00` forever and never ticks; Space (Start/Pause) and `n` (add task) are advertised but unimplemented (issues #98, #99). The repo already contains a rich but **unwired** foundation: complete models (`src/models/`: focus/short_break/long_break, Tasks with 🍅 estimates, Settings with documented defaults), an observer-pattern timer service, seven Bubbles-based components, and a design vision doc (`docs/layout.md`: "monastic" tomato-red ring timer, large digits, one START/PAUSE button, duration capsules, slim add-task bar, stats dashboard). The project constitution requires meaningful use of every Bubbles component. 101 open GitHub issues (#1–#101) track the spec tasks.

Visual direction (informed by image search): dark Pomodoro apps center on a **big time readout in a session-colored progress ring**, a mode wordmark ("FOCUS"), session dots (1/4), current-task line, one primary button (refs: dark GitHub pomodoro "15:37 FOCUS · 1/4", Flocus Focus/Short/Long switch). Charm's lipgloss demo informs tab/dialog styling; btop-style monitors inform the stats tab.

---

## Part A — Current issues (and why they matter)

**Fatal / structural**
1. **`src/services` doesn't compile** — `NewTimerService` declared twice (concrete_timer_service.go:19, timer_service.go:14). Any import breaks the build.
2. **No persistence implementation** — `persistence.go` is interfaces only; tasks/settings/history are lost on exit.

**Advertised but missing (UX lies)**
3. Space Start/Pause shown in status bar, not handled (#98). 4. "Press 'n' to add a task" shown, not handled (#99). 5. No other keys — no reset/skip/navigation/help.

**Timer is fake**
6. Zero-value `TimerSession{}` → `00:00` forever; no tick driver. 7. No session lifecycle: statuses never transition, no focus→break flow, durations hardcoded (ignoring Settings).

**Tasks are fake**
8. `renderTasks()` is a hardcoded string; all task components are orphans.

**Dead-code landmines**
9. `GetRemainingTime()` returns full duration (timer.go:101); `Pause()` no-op. 10. `TaskList.RemoveTask` index drift (task_list.go:142-146). 11. `TimerControl` toggles on any key; `TaskInput.GetTask` creates zero-ID tasks. 12. `Notifier` uses `fmt.Println` (corrupts alt-screen), bogus sound paths.

**Visual issues**
13. One look for every state — no progress indicator, no session count, no color language. 14. Fixed widths, not centered/responsive; title below tabs; status bar advertises dead keys.

## Part B — Improvement plan (ordered todos)

### Phase 0 — Unbreak the foundation
- **T0.1** Merge `timer_service.go` into `concrete_timer_service.go` — one canonical service (keep observer pattern; fix `StartTime` bug).
- **T0.2** Add `models.DefaultSettings()` (25/5/15, interval 4, auto-start breaks); service reads durations from Settings.
- **T0.3** Fix dead-code bugs for wiring: `GetRemainingTime`, `RemoveTask` drift, `TimerControl` focus scoping, real task IDs.
- **T0.4** Rewrite `Notifier` TUI-safe: message-driven (BEL + view flash), sound optional behind `Settings.NotificationType`.

### Phase 1 — Make it work (app core)
- **T1.1** Rebuild `views/app.go`: Model holds Settings, service ref, `[]Task`, tab enum (Timer/Tasks/Stats/Help; Settings later), window size; bridge service events → existing `models/messages.go` msgs (`TimerTickMsg`, …) via channel-fed `tea.Cmd`.
- **T1.2** Keys: `space`/`enter` start/pause/resume, `r` reset, `s` skip, `tab`/`shift+tab` tabs, `a` add task, `j/k`/arrows navigate, `x` toggle done, `d` delete (confirm), `enter` set current task, `?` help, `esc` cancel, `q` quit (confirm if running).
- **T1.3** Session flow: focus → short break → … → long break every `LongBreakInterval`; honor AutoStart settings; record completed sessions.
- **T1.4** Tasks CRUD via real components (title `textinput`, optional description `textarea`, 🍅 estimate); selected task shows under timer ring.
- **T1.5** `persistence_json.go`: JSON at `os.UserConfigDir()/pomodoro/state.json`; load on start, debounced save.

### Phase 2 — Visual redesign (see Part C for exact targets)
- **T2.1** `src/views/styles.go`: centralized palette per state + shared borders/paddings/tab styles.
- **T2.2** Timer centerpiece: ASCII progress ring (evolve `timer_display.go` ●○ arc) + large digits + mode wordmark + session dots + current-task line.
- **T2.3** Controls: state-colored primary START/PAUSE/RESUME; RESET; SKIP; idle duration capsules 15/25/35.
- **T2.4** Header/tabs + today count; **T2.5** Tasks view list + slim add-bar; **T2.6** state-colored status bar with contextual hints; **T2.7** responsive centering + compact mode.

### Phase 3 — Motion & feel (subtle by design)
- **T3.1** `bubbles/progress` spring bar under timer for smooth sub-second fill; ring steps per second.
- **T3.2** Micro-animations: button spinner on transition; ~600ms ring color crossfade on mode switch; completion flash banner; task check ○→◐→● ~300ms; RUNNING chip blink.
- **T3.3** Paused "breathing" (ring dims/brightens ~800ms). Extra tick cmds run only while animating; base redraw 1Hz.

### Phase 4 — Stats, settings, help (constitution: every Bubbles component)
- **T4.1** Stats: today cards + 7-day bar chart + `bubbles/table` recent sessions (`paginator`). **T4.2** Settings: editable durations/auto-start/notification/theme. **T4.3** Help: `bubbles/help` + `key.Binding` everywhere + `viewport` cheat sheet (Glow bonus). **T4.4** Stretch: stopwatch mode, JSON import/export (`filepicker`).

## Part C — Screen-by-screen design targets

**Shared chrome (all screens):** row 1 header: `🍅 Pomodoro` brand left · tabs center-left (`Timer Tasks Stats Help`) with active tab in the session accent + underline · `🍅 3 today` right. Last row status bar: left state chip (`● RUNNING` tomato / `‖ PAUSED` amber / `○ READY` gray / `☕ BREAK` teal), middle contextual key hints (only keys valid on this screen), right live clock. Content vertically centered via `lipgloss.Place`. Palette tokens: focus `#E5484D`, short break `#30A46C`, long break `#0091FF`, paused `#FFB224`, done muted green; text `#EEEEEE` + 40%-dim variant (AdaptiveColor for light terminals); panels use the subtle border, no filled backgrounds — "monastic".

### 2. Timer — idle (READY)
Ring fully `○` and gray; wordmark `FOCUS · READY`; digits show configured duration (`2 5 : 0 0`). Primary button `▶ START` (tomato). Capsule row right of START: `┌15m┐ ┌25m┐ ┌35m┐` — selected capsule outlined in tomato (25m default, AC1.7); pressing one pre-sets duration and starts. Hint line `space start · tab views`.

### 3. Timer — paused
Same layout as running; chip `‖ PAUSED` amber; button becomes `▶ RESUME`; ring freezes at its fraction, rendered dim; digits keep remaining time; "breathing" (T3.3). Status hints add `space resume`.

### 4. Timer — short / long break
Color system swaps globally (teal / blue): ring, primary button (`☕ PAUSE`), status chip. Wordmark `SHORT BREAK` / `LONG BREAK`; a dim suggestion line ("stretch · water · look away" rotating per break). After a 4th focus: session dots `●●●●`, line "4/4 — nice work, long break earned".

### 5. Timer — completion flash (transient, ~2.5s)
Centered banner panel over the ring, BEL + fade in/out:
```
        ╭─────────────────────────────────────────────╮
        │   🍅 Focus session complete — time for a break  │
        ╰─────────────────────────────────────────────╯
```
Auto-advances per AutoStart settings; skip with any key.

### 6. Tasks view
```
  🍅 Pomodoro    Timer   ━ Tasks ━   Stats   Help      3 open · 2 done

     ❯ ○  Write UI plan doc                    🍅🍅🍅  1/3
       ◐  Review PR #12                       🍅🍅    0/2
       ○  Inbox zero                          🍅      0/1
       ●  Standup notes          ✓ done       🍅🍅    2/2     ← dim + strikethrough

     a add · x toggle · d delete · enter focus timer · j/k move

     ── new task ────────────────────────────────────────────
     ▏ title…                                    (esc to cancel)
```
Delegate: status glyph ○ todo / ◐ in-progress / ● done; 🍅 glyphs = estimate with done fraction `1/3`; cursor `❯` + selected-row highlight. `a` opens the slim bar (single row); `tab` inside it expands to description (`textarea`) + estimate stepper (`+/-`); `enter` saves. `enter` on a list row sets it as the timer's current task. Empty state: small tomato ASCII + "press a to plant your first tomato".

### 7. Stats view
```
   ┌ Today ──────────┐  ┌ Focus time ─────┐  ┌ Streak ─────────┐
   │    🍅 × 3       │  │    1h 15m       │  │    4 days       │
   └─────────────────┘  └─────────────────┘  └─────────────────┘

   Last 7 days                    Recent sessions        (pg 1/2 · ←→)
   Mon ▇▇▇▇ 4                     WHEN   TYPE    LEN  TASK
   Tue ▇▇▇▇▇▇ 6                   14:02  ●Focus  25m  Write UI plan doc
   Wed ▇▇ 2                       13:35  ☕Break   5m  —
   …                              12:58  ●Focus  25m  Review PR #12
```
Three stat cards (today 🍅, focus time, day streak); `▁▃▅▇` bar chart; `bubbles/table` with type glyph in session color; `paginator` (`←/→`). Later: calendar heat-map per layout.md.

### 8. Settings view (Phase 4)
Label/value rows, inline edit, saved on change: `Focus duration [25] min · Short break [5] · Long break [15] · Long break every [4] · Auto-start breaks [✓] · Auto-start focus [ ] · Notify (visual/bell/sound) · Theme dark/light`. `esc` returns to Timer.

### 9. Help overlay (Phase 4)
`?` opens a bordered modal over dimmed content: grouped keybindings (General / Timer / Tasks / Stats), rendered by `bubbles/help`; `j/k` scroll extended cheat sheet in a `viewport`; `?`/`esc` closes.

### 10. Quit confirmation (modal, only while running)
```
     ╭───────────────────────────────────────────╮
     │  Session still running — quit anyway?     │
     │    y quit    n / esc keep going           │
     ╰───────────────────────────────────────────╯
```

### 11. Compact mode (< 80×20)
Hide capsules and % label; ring shrinks to 5 rows (or a plain 40-char bar); tabs collapse to initials with the active one colored; status hints truncated to two keys; tasks list hides 🍅 estimate glyphs.
