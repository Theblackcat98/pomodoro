# Pomodoro APP

## Goal:

Build a TUI Pomodoro App with the challenge that we are going to use every UI element and every feature of these libraries and frameworks to make a pomodoro timer in the TUI.


### https://github.com/charmbracelet/lipgloss
Style definitions for nice terminal layouts. Built with TUIs in mind

### https://github.com/charmbracelet/bubbletea
Our main framework, we will build the app with this.

### https://github.com/charmbracelet/bubbles
This is very very important; there are a lot of components and UI elements that we must implement. (see bubble.md)

### https://github.com/charmbracelet/glow
This is not a strict necessity as it's mainly a markdown renderer; bonus points if we can put it in here.
